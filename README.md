# Sem6
Спринт 1: Лексический анализатор (Lexer)
Что сделано:
- ✅ Формальная спецификация языка в EBNF нотации
- ✅ Полноценный лексер, распознающий все токены языка
- ✅ Обработка комментариев (// и /* */)
- ✅ Отслеживание позиции (строка/колонка)
- ✅ Обработка ошибок с понятными сообщениями
- Комплексное тестирование (20+ тестов) (в процессе)
- ✅ Поддержка UTF-8


- Язык реализации: Python 3.8+
- Кодировка: UTF-8

- Установка и запуск
Предварительные требования:
- Python 3.8 или выше
- Git (опционально)

Установка:

```bash
# 1. Клонировать репозиторий
git clone https://github.com/yourusername/compiler-project.git
cd compiler-project

# 2. Запустить лексер на примере
python src/main.py --input examples/hello.src

# 3. Сохранить результат в файл
python src/main.py --input examples/hello.src --output tokens.txt

# 4. Использовать Make
make run ARGS="--input examples/hello.src"


python src/main.py
Опции:
  --input FILE, -i FILE    Входной файл с исходным кодом (обязательно)
  --output FILE, -o FILE   Выходной файл для токенов (если не указан, вывод в консоль)
  --help, -h               Показать справку

Make комманды:
make build    # Подготовка проекта (ничего не делает для Python)
make test     # Запуск всех тестов
make run      # Запуск с аргументами (make run ARGS="--input file.src")
make clean    # Очистка временных файлов


СТРОКА:КОЛОНКА ТИП_ТОКЕНА "ЛЕКСЕМА" [ЗНАЧЕНИЕ]
Пример:
1:1 KW_FN "fn"
1:4 IDENTIFIER "main"
1:8 LPAREN "("
1:9 RPAREN ")"
1:11 LBRACE "{"
2:5 KW_INT "int"
2:9 IDENTIFIER "x"
2:11 OP_ASSIGN "="
2:13 INT_LITERAL "42" 42
2:15 SEMICOLON ";"
5:1 END_OF_FILE ""


Спецификация языка:
Ключевые слова:
if, else, while, for, int, float, bool, return, true, false, void, struct, fn
Типы литералов:
Целые числа: 42, -17, 0
Числа с плавающей точкой: 3.14, -0.5, 100.0
Строки: "Hello, World!", ""
Булевы: true, false
Арифметические: +, -, *, /, %
Сравнения: ==, !=, <, <=, >, >=
Логические: &&, ||, !
Присваивание: =, +=, -=, *=, /=
Разделители:
( ) { } [ ] ; , :
Комментарии:
// Однострочный комментарий
/* Многострочный
   комментарий */
/* Вложенные /* комментарии */ поддерживаются */
